# PRODX POS — Final Logo Standard

Status: **FINAL / LOCKED**

This document establishes the approved PRODX POS logo direction as the project brand reference for UI, authentication/login, dashboard, Figma designs, and production application surfaces.

## Approved identity

- Primary emblem: geometric **P** monogram.
- Primary emblem color: premium orange/gold gradient, bright and warm.
- Wordmark: **PRODX POS** in a bold, dark, highly legible geometric style.
- Supporting line: **DEVERLOPED BY THODSAWAT**.
- Primary presentation background: clean white/light neutral background.
- Visual character: premium, modern, professional, crisp, smooth, balanced.

## Rendering rules

- Keep the P proportions and overall silhouette consistent with the approved final visual reference.
- Keep the P visually smaller and proportionate to the PRODX POS wordmark; do not enlarge it independently.
- Use smooth edges and clean vector-like geometry.
- Keep depth subtle. Avoid excessive 3D bevels, reflections, glow, or heavy shadows.
- Preserve the orange/gold gradient as the main visual accent.
- Keep PRODX POS dark/black for maximum contrast and brand consistency.
- Maintain balanced spacing between the P emblem, wordmark, and supporting line.

## Usage hierarchy

1. Full logo: P + PRODX POS + DEVERLOPED BY THODSAWAT.
2. Compact brand mark: P monogram only.
3. Wordmark: PRODX POS where the P monogram is not practical.

## Design-system requirement

All future UI work must reference this locked logo direction. Any logo change must be treated as a deliberate brand revision rather than an incidental UI adjustment.

The logo should be implemented as a reusable brand asset/component rather than recreated independently in individual screens.

## Light / Dark Mode

- Light mode: use the approved orange/gold P with dark wordmark.
- Dark mode: retain the same P geometry and brand gradient, with an appropriate light wordmark treatment for contrast.
- Do not create a different logo shape for dark mode.
